About QuickNotes

QuickNotes is a simple application for capturing ideas, reminders, and important thoughts in one place. It helps users keep their notes organized and easy to access.

How to use QuickNotes

  1. Open the QuickNotes application.
  2. Type your note into the note box.
  3. Click the Add Note button to save your note.

Features

  • Create quick notes.
  • View saved notes.
  • Organize important ideas and reminders.
  • Use keyboard shortcuts to work efficiently.

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + S Save the file in VS Code
